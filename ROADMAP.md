# Roadmap

Planned improvements for future versions.

## Product improvements

- Add restore-point guidance before applying system-level remediation.
- Add rollback notes for each remediation action.
- Add scheduled local scans.
- Add side-by-side report comparison between scans.
- Add clearer severity explanations for non-technical users.

## Security and coverage improvements

- Map checks to CIS Controls or Microsoft security baseline categories where appropriate.
- Add more Windows Defender configuration checks.
- Add more audit policy checks.
- Add optional enterprise-only checks for domain-joined devices.
- Add local CVE exposure notes where Windows build information is available.

## Engineering improvements

- Add unit tests for scoring and finding serialization.
- Add static validation for remediation allowlists.
- Add a packaged Windows executable release.
- Add automated screenshot generation for documentation.
- Add structured report schemas.
